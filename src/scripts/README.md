## Scripts

### Restore-Packages.ps1
PowerShell script to restore NuGet packages using multiple methods.

**Usage:**
```powershell
# From solution root
.\scripts\Restore-Packages.ps1

# Force restore (cleans obj/bin first)
.\scripts\Restore-Packages.ps1 -Force
```

**What it does:**
1. Tries MSBuild restore (`/t:Restore`)
2. Tries NuGet.exe restore (if available)
3. Tries dotnet restore (if available)
4. Reports which methods succeeded
5. Checks for missing assets files
6. Provides troubleshooting guidance

**When to use:**
- Build fails with "Assets file not found" errors
- After cloning repository
- After switching branches
- When packages seem out of date
- Troubleshooting package issues

### Build-Performance.ps1
PowerShell script to build ACAT solution and ACATTalk with performance monitoring.

**Usage:**
```powershell
# From solution root
.\scripts\Build-Performance.ps1 [-Configuration <Debug|Release>] [-Clean] [-Run] [-SkipRestore]

# Examples
.\scripts\Build-Performance.ps1 -Run              # Build and run
.\scripts\Build-Performance.ps1 -Clean -Run       # Clean, build, and run
.\scripts\Build-Performance.ps1 -Configuration Debug -Run  # Debug build
.\scripts\Build-Performance.ps1 -SkipRestore     # Skip NuGet restore
```

**What it does:**
1. Restores NuGet packages (unless `-SkipRestore`)
2. Builds entire ACAT solution
3. Rebuilds ACATTalk with PERFORMANCE symbol defined
4. Optionally runs ACATTalk with `-Run` flag

**Parameters:**
- `-Configuration` - Build configuration (Debug or Release, default: Release)
- `-Clean` - Clean solution before building
- `-Run` - Run ACATTalk after successful build
- `-SkipRestore` - Skip NuGet package restore step

### Build-Performance.bat
Batch file alternative for building with performance monitoring.

**Usage:**
```cmd
scripts\Build-Performance.bat
```

Double-click or run from command prompt. Automatically restores packages, builds solution, rebuilds ACATTalk with PERFORMANCE, and prompts to run.

### Analyze-Performance.ps1
PowerShell script to analyze performance reports generated by ACATTalk.

**Usage:**
```powershell
# From solution root or scripts directory
.\scripts\Analyze-Performance.ps1 [-ReportsPath <path>] [-TopN <number>] [-Compare] [-Export]

# Examples
.\scripts\Analyze-Performance.ps1                 # Analyze latest report
.\scripts\Analyze-Performance.ps1 -Compare        # Compare with previous run
.\scripts\Analyze-Performance.ps1 -Export         # Export summary to file
.\scripts\Analyze-Performance.ps1 -TopN 10        # Show top 10 slowest operations
```

**What it does:**
- Displays performance summary from latest report
- Shows top N slowest operations
- Memory usage analysis with color coding
- Compare mode to diff against previous run
- Export option to save summary

**Parameters:**
- `-ReportsPath` - Path to reports directory (default: `%USERPROFILE%\ACATTalk_PerformanceReports`)
- `-TopN` - Number of slowest operations to show (default: 5)
- `-Compare` - Compare latest with previous report
- `-Export` - Export summary to text file

### Analyze-PerformanceTrends.ps1
PowerShell script to analyze performance trends across multiple reports over time.

**Usage:**
```powershell
# From solution root or scripts directory
.\scripts\Analyze-PerformanceTrends.ps1 [-ReportsPath <path>] [-LastN <number>] [-Files <files>] [-Metrics <metrics>] [-ShowChart] [-IncludeStatistics] [-ExportHtml] [-ExportCsv]

# Examples
.\scripts\Analyze-PerformanceTrends.ps1                           # Analyze last 10 reports
.\scripts\Analyze-PerformanceTrends.ps1 -LastN 20                 # Analyze last 20 reports
.\scripts\Analyze-PerformanceTrends.ps1 -ShowChart                # Display ASCII trend charts
.\scripts\Analyze-PerformanceTrends.ps1 -IncludeStatistics        # Show detailed statistics
.\scripts\Analyze-PerformanceTrends.ps1 -ExportHtml               # Export to HTML report
.\scripts\Analyze-PerformanceTrends.ps1 -ExportCsv                # Export trend summary to CSV
.\scripts\Analyze-PerformanceTrends.ps1 -Metrics @('TotalStartupTime','PeakMemoryUsage')  # Specific metrics only
.\scripts\Analyze-PerformanceTrends.ps1 -Files @('report1.csv','report2.csv','report3.csv')  # Specific files
.\scripts\Analyze-PerformanceTrends.ps1 -ShowChart -IncludeStatistics -ExportHtml  # All features
```

**What it does:**
- Analyzes trends across multiple performance reports
- Shows first vs. last values with change percentages
- Identifies improving and degrading metrics
- Calculates statistical measures (min, max, average, median, standard deviation)
- Displays trend indicators (▼▼ improving, ▲▲ degrading, ═ stable)
- Optional ASCII charts for visual trend analysis
- Volatility analysis to identify unstable metrics
- Category-based trend grouping
- HTML export with interactive tables
- CSV export for further analysis

**Parameters:**
- `-ReportsPath` - Path to reports directory (default: `%USERPROFILE%\ACATTalk_PerformanceReports`)
- `-LastN` - Number of most recent reports to analyze (default: 10)
- `-Files` - Specific report files to analyze (overrides LastN)
- `-Metrics` - Specific metrics to analyze (default: key metrics like TotalStartupTime, PeakMemoryUsage, etc.)
- `-ShowChart` - Display ASCII trend charts for each metric
- `-IncludeStatistics` - Show detailed statistics (min, max, avg, stddev)
- `-ExportHtml` - Export results to HTML file
- `-ExportCsv` - Export trend summary to CSV file
- `-ChartWidth` - Width of ASCII charts (default: 80)
- `-ChartHeight` - Height of ASCII charts (default: 15)

## Workflows

### Development Workflow - Track Your Changes

When making performance-related changes, track trends over multiple test runs:

```powershell
# 1. Build with performance monitoring
.\scripts\Build-Performance.ps1

# 2. Run ACATTalk multiple times (3-5 runs for baseline)
# Exit normally after each run

# 3. Analyze trends
.\scripts\Analyze-PerformanceTrends.ps1 -ShowChart -IncludeStatistics

# 4. Make your code changes

# 5. Rebuild and run multiple times
.\scripts\Build-Performance.ps1 -Run

# 6. Compare trends before and after changes
.\scripts\Analyze-PerformanceTrends.ps1 -LastN 10 -ShowChart -ExportHtml
```

### CI/CD Integration - Track Regression

```powershell

.\scripts\Analyze-PerformanceTrends.ps1 -LastN 30 -ExportCsv -ExportHtml

# Upload the HTML and CSV as build artifacts for historical tracking
```

### Release Validation - Compare Across Versions

```powershell
# Select specific reports from different versions
$v1Reports = @('ACATTalk_Performance_20240101_120000.csv', 'ACATTalk_Performance_20240101_130000.csv')
$v2Reports = @('ACATTalk_Performance_20240201_120000.csv', 'ACATTalk_Performance_20240201_130000.csv')

.\scripts\Analyze-PerformanceTrends.ps1 -Files $v1Reports -ExportHtml
.\scripts\Analyze-PerformanceTrends.ps1 -Files $v2Reports -ExportHtml
```

## Performance Reports

Reports are saved to: `%USERPROFILE%\ACATTalk_PerformanceReports\`

Two files per session:
- `ACATTalk_Performance_YYYYMMDD_HHmmss.txt` - Human-readable report
- `ACATTalk_Performance_YYYYMMDD_HHmmss.csv` - Machine-readable data

## Metrics Collected

- **Startup Time** - Application launch to UI ready
- **Component Initialization** - Logging, DI, Context, TTS, Word Prediction
- **Memory Usage** - Start, peak, end, growth
- **UI Performance** - Panel creation times
- **Shutdown Time** - Cleanup and disposal

## How Performance Monitoring Works

1. Build script defines `PERFORMANCE` conditional compilation symbol for ACATTalk
2. Performance instrumentation code in `PerformanceMonitor.cs` is compiled
3. Key operations are timed and metrics collected
4. On application exit, reports are generated automatically
5. Analysis script provides insights from reports

## Build Process

The build script uses a two-stage approach:

**Stage 1: Build Solution**
```
msbuild ACAT.sln /t:Restore,Build
```
Ensures all dependencies (ACATCore, ACATExtension, AppCommon, etc.) are built.

**Stage 2: Rebuild ACATTalk with PERFORMANCE**
```
msbuild ACATTalk.csproj /t:Rebuild /p:DefineConstants="TRACE;PERFORMANCE"
```
Rebuilds only ACATTalk with performance monitoring enabled.

This ensures:
- ✅ All dependencies are up-to-date
- ✅ Only ACATTalk has performance overhead
- ✅ Fast incremental builds
- ✅ NuGet packages are restored

## NuGet Package Restore

The build script automatically restores NuGet packages using:
1. NuGet.exe if available in PATH
2. MSBuild restore (`/t:Restore`) as fallback

To skip restore (faster for repeated builds):
```powershell
.\scripts\Build-Performance.ps1 -SkipRestore
```

## Troubleshooting

**Build fails with dependency errors**
```powershell
# Clean and rebuild everything
.\scripts\Build-Performance.ps1 -Clean
```

**NuGet restore fails**
```powershell
# Manually restore packages first
nuget restore ACAT.sln
# Or use MSBuild
msbuild ACAT.sln /t:Restore
```

**No performance reports generated**
- Ensure you exit ACATTalk normally (not crash)
- Check `%USERPROFILE%\ACATTalk_PerformanceReports\` exists
- Verify PERFORMANCE symbol was defined (check build output)

**Scripts don't run**
- Ensure PowerShell execution policy allows scripts:
  ```powershell
  Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned
  ```
